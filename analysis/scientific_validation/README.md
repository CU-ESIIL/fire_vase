# Scientific validation package

Start with [final_report.md](final_report.md), [audit_report.md](audit_report.md), [final_claim_matrix.md](final_claim_matrix.md), and [PRISM_HANDOFF.md](PRISM_HANDOFF.md). Tables are generated by `scripts/validate_fire_vase_science.py`; prose and claims by `scripts/finalize_fire_vase_science.py`. The v2 candidate statistics remain separately identified. Run `PYTHONPATH=src:scripts MPLBACKEND=Agg MPLCONFIGDIR=/tmp/fire-vase-v2-mpl OPENBLAS_NUM_THREADS=1 .venv/bin/python scripts/validate_fire_vase_science.py`, then the normal figure pipeline with `--render-only`. The full normal pipeline also invokes this validation stage.

No new external observational data were ingested. Null simulations are labeled reference distributions. CSVs use fixed seeds and 12-digit serialization; the freeze manifest records hashes. Reused full v2 sensitivity grids are not mislabeled newly rerun.
