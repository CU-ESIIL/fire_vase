# Findings

<p class="fire-page-deck">Four results define the current evidence: developmental histories vary along broad gradients; their order matters; recent state dominates next-day prediction; and matched mismatches identify what to measure next.</p>

## The scientific argument

<section class="fire-finding-grid fire-finding-grid--single">
<a class="fire-finding-card" href="developmental-pathways/">
<span>Finding 01 · N = 10,246</span>
<h2>Fires follow different developmental pathways.</h2>
<p>The main coordinates describe broad differences in when growth was allocated:
earlier versus later, and concentrated versus more distributed. Five axes
summarize 89.4% of standardized shape variance.</p>
<strong>See the morphospace →</strong>
</a>
<a class="fire-finding-card" href="temporal-ordering/">
<span>Finding 02 · Null sample N = 4,000</span>
<h2>The order of growth contains information.</h2>
<p>Rearranging the same observed increments changes developmental traits and
space coverage. Real histories allocate 54.1% of growth to the first half on
average, versus 50.0% after shuffling.</p>
<strong>See the ordering test →</strong>
</a>
<a class="fire-finding-card" href="weather-and-state/">
<span>Finding 03 · 87,944 transitions from 31,700 fires</span>
<h2>Recent fire state explains much more than weather alone.</h2>
<p>The region-held-out autoregressive state model reaches R² = 0.448. Weather
adds ΔR² = 0.005; the full weather × state model adds ΔR² = 0.018.</p>
<strong>Compare the evidence →</strong>
</a>
<a class="fire-finding-card" href="mismatched-fires/">
<span>Finding 04 · 9,212 eligible complete fires</span>
<h2>Similar weather can accompany different histories.</h2>
<p>Observed mismatch among weather-matched pairs is 49.7%, close to the 50.4%
conditional-permutation mean. The examples locate useful contrasts without
claiming excess mismatch or a mechanism.</p>
<strong>See the matched fires →</strong>
</a>

## Read the evidence in sequence

The findings move from **representation** to **ordering**, then from
**prediction** to **unresolved mechanism**. This sequence prevents weather or
endpoint outcomes from defining the response they are later asked to explain.
