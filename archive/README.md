# Archive

This folder preserves material that is useful for project history, review, or
traceability but should not be part of the public manuscript-supplement website
navigation.

## Contents

- `manuscript_history/`: superseded manuscript drafts, citation/compliance
  checks, and formal review logs. These files are retained as part of the
  project record and AI/prompt-assisted review history.
- `legacy_cubedynamics_docs/`: older generic CubeDynamics and VASE
  documentation copied during the repository split. The current website now
  focuses on manuscript reproduction.
- `visual_checks/`: ad hoc root-level visual QA artifacts preserved from early
  Fire VASE viewer checks.

Do not delete prompt logs, formal review logs, AI transparency records, or
manuscript-history files during cleanup. Move them here if they no longer belong
in the public docs site.
