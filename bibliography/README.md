# Fire VASE Bibliography

This folder contains Zotero-importable bibliography files for the Fire VASE manuscript.

## Files

- `fire_vase_manuscript.bib`: canonical 16-reference bibliography from the current Science-style manuscript draft.

## Zotero Import

In Zotero:

1. Choose `File` -> `Import...`.
2. Select `A file`.
3. Choose `bibliography/fire_vase_manuscript.bib`.
4. Import into a new collection named `Fire VASE Manuscript`.

The BibTeX entries include stable citation keys and `keywords` fields. Zotero imports those keywords as tags.
